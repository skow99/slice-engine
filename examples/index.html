Slice Engine examples

Each example is one HTML page and a few ES modules, importing the engine from ../../src/index.js. No build step.

  1. Hello, stack: one model built in code, turning, with shadows and the four times of day.
  2. Model viewer: models from code, ASCII layers and a PNG slice sheet. Drop your own sheet on the page to see it.
  3. Crystal Rover: a small complete game: driving, collisions, trees, particles, sound, music, menus, a saved best time, touch controls.
  4. Garden Cart: the game docs/tutorial.md builds, one step at a time.
